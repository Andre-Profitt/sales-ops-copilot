# think-cell setup runbook — LAND-monthly deck

One-time wiring of the SimCorp-branded LAND template (`assets/LAND_template.pptx`) to a per-director formula-driven workbook (`state/<period>/<director>/land.model.xlsx`). Once the datalinks are in place, monthly deck refresh is two clicks: open the per-director PPTX and hit "Update charts now."

## Prerequisites

- think-cell 14+ installed in PowerPoint for Mac (trial or licensed)
- Office 365 / 2021+ running in **native Apple Silicon mode** (not Rosetta — KB0238)
- A per-director model workbook generated by `python3 scripts/land_brief.py --director "<Name>" --period 2026-Q2`

## First-launch on Mac (5 minutes, before any wiring)

Sources: <https://www.think-cell.com/en/resources/manual/installation>, <https://www.think-cell.com/en/resources/manual/first-installation>

1. Double-click the downloaded installer (`.pkg`) and follow the prompts. Enter admin password when asked.
2. **macOS 15 (Sequoia) only:** approve the data-access prompt during install ("think-cell requires data access permissions during installation on macOS 15 and later"). System Settings → Privacy & Security may surface this.
3. Quit and reopen PowerPoint after install.
4. **First launch of PowerPoint and Excel after install:** macOS shows a file-access permission prompt. **Click Allow** — if you click Don't Allow, the think-cell ribbon stays disabled and there is no in-app retry; you have to grant the permission via System Settings → Privacy & Security → Files and Folders.
5. The think-cell ribbon appears as a group inside PowerPoint's **Insert** tab.
6. **License-key dialog** appears on first use. Paste the trial key from the email — same dialog handles both trial and licensed activation; no separate flow.

## Per-director workflow (one-time wiring, ~30 min for first director)

1. Open `assets/LAND_template.pptx` in PowerPoint
2. **File → Save As** → `state/<period>/<director>/<director>-LAND-<period>.pptx`
3. Open `state/<period>/<director>/land.model.xlsx` in Excel (think-cell needs both files open simultaneously to bind)
4. For each placeholder slide below, replace the dashed-blue placeholder rectangle with a datalinked think-cell chart. The actual click sequence is **Excel-first** (NOT PowerPoint-first as I originally wrote):
   - Delete the placeholder rectangle in PowerPoint
   - In **Excel**, select the range listed in the table below (include header labels)
   - **Excel ribbon → Insert tab → think-cell group → "Link to PowerPoint"** dropdown → pick the chart type
   - PowerPoint activates; click on the empty slide to place the chart
   - To bind to an existing chart placeholder instead of placing fresh, use **"To Existing Element"** in the same dropdown

   For binding a single Excel cell to a text frame in PowerPoint (e.g., the 3 headline KPIs on slide 2):
   - In **Excel**, select the single cell
   - In **PowerPoint**, place cursor inside a text frame
   - **Insert → think-cell → Elements → Text Linked to Excel**

   Source: <https://www.think-cell.com/en/resources/manual/exceldatalinks>

5. **File → Save** when done

## Subsequent months (per director, ~2 minutes)

1. Run `python3 scripts/land_brief.py --director "<Name>" --period <Period>` — regenerates `land.model.xlsx`
2. Open the per-director PPTX from above. **Don't close it during refresh** — cached datalink values persist only while the deck is open (per think-cell manual).
3. Each stale chart shows a green frame with an Update icon → click it. Or batch-refresh via **Insert → think-cell → Tools → Data Links** dialog → "Update all".
4. **File → Save**

There is **no documented Mac keyboard shortcut for refresh**; it stays ribbon-driven.

The xlsx layout contract (named ranges + sheet structure) is stable across runs — datalinks won't break unless we restructure sheet positions.

## The two-workbook split

Slides 2 / 4 / 5 / 6 / 12 / 15 / 16 / 17 / 18 / 19 / 21 / 22 / 23 / 24 / 25 read the formula-driven **`model.xlsx`** (the model). Slides 7 / 8 / 9 / 11 / 13 / 26 read the legacy **`land.xlsx`**. Both workbooks live in the same per-director directory; open both in Excel before wiring so think-cell sees both as datalink sources.

Why split: the named-account tables (Top deals, Pending Commercial Approval, At-risk renewals, Forecast Category, Action items) are precomputed lists, not formulas — they live in the legacy companion. The model owns the formula-traceable KPIs and the new Tier-A insight sheets (`Retention`, `Territory_Performance`, `Wins_Losses_QTD`, `Stale_Activity`, `Sales_Velocity`, `Account_Expansion`, `Pipeline_Creation_Velocity`). Phase 2 plan: migrate the named-account tables to the model so everything reads from one workbook.

## Color conventions in the deck

Match the FAST/ICAEW conventions already applied in the model workbook:

| Role                         | Color     | Where used                                                             |
| ---------------------------- | --------- | ---------------------------------------------------------------------- |
| Brand blue                   | `#083EA7` | Slide titles, primary chart series, header bars                        |
| Brand secondary (near-black) | `#1A1D31` | Body text, secondary chart series                                      |
| Coral (alert)                | `#EF3E4A` | HIGH-priority cells, zombie age bucket, single-deal-risk flag when YES |
| Orange (caution)             | `#FB9B2A` | MEDIUM-priority cells, late-stage <30% threshold flag                  |
| Gray (info)                  | `#666666` | LOW-priority, footnotes, caveats                                       |

**Mac-specific limitation on color application:** think-cell's color-scheme automation API (`LoadStyle` / `LoadStyleForRegion`) is **Windows-only**. On Mac you have two options:

1. **Per-feature Fill (recommended for our 12 charts)** — right-click any series/segment → **Fill** → pick or enter a color manually. Slower but works without external files.
2. **Per-deck style file** — load a `.xml` style file once per deck via **Insert → think-cell → Tools → Change Style**. The style file declares `srgbClr val="RRGGBB"` entries and applies the palette globally. Build it once, reuse across all 9 directors.

Option 2 is the right path long-term; for the first wiring pass, option 1 is fastest.

## Mac keyboard shortcuts that matter

think-cell's documented Mac shortcuts (per <https://www.think-cell.com/en/resources/manual/keyboardshortcuts>):

| Shortcut          | Effect                                                                   |
| ----------------- | ------------------------------------------------------------------------ |
| `Cmd+A`           | Select all elements of the same type on slide                            |
| `Cmd+Opt+arrows`  | Move selection across shapes                                             |
| `Ctrl+Opt+arrows` | Duplicate the selected element (good for repeating labels across slides) |
| `F2`              | Toggle text-edit mode                                                    |
| `Opt+Enter`       | Line break inside the datasheet                                          |

**No documented shortcuts exist** for create-chart, link-to-Excel, or refresh — those stay ribbon/menu driven. Don't burn time looking.

## Troubleshooting

**Datalink shows `#REF!` after refresh** — the xlsx range moved (a sheet got renamed, a row got inserted). Check the bound range in think-cell's datalink dialog and re-point.

**think-cell ribbon missing** — Office is running in Rosetta. Quit PowerPoint, in the Applications folder right-click → Get Info → uncheck "Open using Rosetta," reopen.

**Charts say "Datalink: not found"** — both files must be open in their parent apps (xlsx in Excel, pptx in PowerPoint) for refresh to work. think-cell uses the inter-app COM bridge, which only works when both apps are running.

**Per-director PPTX got out of sync with template** — delete the per-director PPTX, save-as from `LAND_template.pptx` again, and re-run the wiring. The template is the canonical layout source.
